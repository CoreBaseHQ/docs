CoreBase is the managed memory and tool-calling layer for the AI features inside your product. One API for chat, one widget to embed, and a panel where you connect each of your customers' databases — with the schema annotations and glossary that turn raw SQL into answers your customers' teams actually understand.

## The 60-second tour

Embed into your product:

```bash
# 1. Get a CoreBase API token
export COREBASE_API_KEY=cb_live_a1b2c3...

# 2. Add your own LLM provider key in the panel
#    (Settings → LLM keys → paste Anthropic/OpenAI/Gemini key)

# 3. Connect a customer's database in the panel
#    (Sources → Add → Postgres → paste DSN)

# 4. Ask — OpenAI-compatible streaming response
curl -N -X POST https://api.corebasehq.com/v1/chat/completions \
  -H "Authorization: Bearer $COREBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "corebase",
    "messages": [{"role":"user","content":"Top 5 customers by revenue this quarter?"}],
    "stream": true
  }'
```

Self-host the agent:

```bash
curl -fsSL https://get.corebasehq.com | sh

cat > coremcp.yaml <<EOF
sources:
  - name: erp
    type: mssql
    dsn: "sqlserver://core_ro:pass@10.0.0.5:1433?database=ERP&encrypt=disable"
    readonly: true
EOF
```
