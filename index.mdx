CoreBase is a **governed AI agent platform**: connect your data and build agents on top of it — agents that query, act, and run on a schedule or an event. Read-only by default, audited end to end.

Built for teams shipping AI features into their own product — for their own customers' data.

Connect a cloud database in minutes. When you need it, the same agents reach the systems most tools can't — the SQL Server behind a firewall, the air-gapped network an auditor won't open — through [CoreMCP](/coremcp/intro), so raw rows never leave your perimeter.

## Call it from your own apps

CoreBase also exposes an OpenAI-compatible endpoint, so you can drive the same governed agents from your code:

```bash
# 1. Get a CoreBase API token (panel → Security → API Tokens)
export COREBASE_API_KEY=cb_live_a1b2c3...

# 2. Add your own LLM provider key in the panel
#    (Settings → LLM keys → paste Anthropic / OpenAI / Gemini key)

# 3. Ask — OpenAI-compatible streaming response
curl -N -X POST https://api.corebasehq.com/api/v1/chat/completions \
  -H "Authorization: Bearer $COREBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "corebase",
    "messages": [{"role":"user","content":"Top 5 customers by revenue this quarter?"}],
    "stream": true
  }'
```
