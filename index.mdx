CoreBase is a **governed AI agent platform**. You connect your systems — databases, REST and GraphQL APIs, Slack and Microsoft 365, and 50+ SaaS apps — and build AI agents on top: agents that write and run queries, fire on a schedule or an event, and chain into multi-step flows. Every action is read-only by default, scoped per tenant, and audited.

Connect a cloud database in minutes. And when you need it, the same agents reach the systems most tools can't: the SQL Server 2000 behind a firewall, the Firebird file under a Delphi ERP, the air-gapped network an auditor won't let you open — through [CoreMCP](/coremcp/intro), a zero-trust agent that dials outbound only, so raw rows never leave your perimeter unless you choose.

## Call it from your own apps

CoreBase also exposes an OpenAI-compatible endpoint, so you can drive the same governed agents from your code:

```bash
# 1. Get a CoreBase API token (panel → Settings → Developer)
export COREBASE_API_KEY=cb_live_a1b2c3...

# 2. Add your own LLM provider key in the panel
#    (Settings → LLM keys → paste Anthropic / OpenAI / Gemini key)

# 3. Ask — OpenAI-compatible streaming response
curl -N -X POST https://api.corebasehq.com/v1/chat/completions \
  -H "Authorization: Bearer $COREBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "corebase",
    "messages": [{"role":"user","content":"Top 5 customers by revenue this quarter?"}],
    "stream": true
  }'
```
