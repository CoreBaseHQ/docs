CoreBase wires your databases into Claude, Cursor, and any MCP client through a Go agent that runs on your network. MSSQL, REST, GraphQL — schema-aware, read-only by default, zero raw data egress.

## The 60-second install

```bash
# Install
curl -fsSL https://get.corebasehq.com | sh

# Configure (or use docker)
cat > coremcp.yaml <<EOF
sources:
  - name: erp
    type: mssql
    dsn: "sqlserver://core_ro:pass@10.0.0.5:1433?database=ERP&encrypt=disable"
EOF

# Wire to Claude Desktop
cat ~/Library/Application\ Support/Claude/claude_desktop_config.json
# {"mcpServers": {"corebase": {"command": "/usr/local/bin/coremcp", "args": ["serve"]}}}
```

Open Claude Desktop. Your tables are now tools.
