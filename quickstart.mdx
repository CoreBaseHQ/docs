---
title: "Quickstart"
description: "Connect a database and run your first query in 5 minutes."
---

This guide takes you from zero to your first natural-language query. You'll need shell access to a server that can reach your database and a CoreBase account.

<Steps>
  <Step title="Create an account">
    Sign up at [app.corebasehq.com](https://app.corebasehq.com). New organizations start on the **Free** plan with a $1 trial credit — enough for ~300 small queries.
  </Step>
  <Step title="Install CoreMCP on your server">
    CoreMCP is a small Go binary that talks to your databases locally and tunnels schema metadata to CoreBase. It never sends raw rows over the network.

    Grab the latest release for your platform from [github.com/corebasehq/coremcp/releases](https://github.com/corebasehq/coremcp/releases), or build from source:

    ```bash
    git clone https://github.com/corebasehq/coremcp.git
    cd coremcp && go build -o coremcp ./cmd/coremcp
    ```

    See [CoreMCP installation](/coremcp/install) for the full setup, including Docker and air-gap.
  </Step>
  <Step title="Register the agent">
    In the panel, open **Sources → Add agent** and copy the agent token. Drop your `coremcp.yaml` next to the binary:

    ```yaml
    server:
      name: "coremcp-agent"
      transport: "stdio"

    sources:
      - name: "erp_prod"
        type: "mssql"
        dsn: "sqlserver://core_ro:password@10.0.0.5:1433?database=ERP&encrypt=disable"
        readonly: true
    ```

    Today only **MSSQL** is fully supported; Firebird is on the way. See [Connect a data source](/coremcp/connect) for the full DSN catalog.
  </Step>
  <Step title="Sync your schema">
    In **Sources**, click **Sync schema**. CoreBase reads table and column metadata, hashes identifiers, and stores them encrypted on our side. The agent stays online and answers schema or query requests on demand.

    <Tip>
      Free plan: Corporate Memory is **disabled** — the model only sees raw schema names. Pro and Team unlock adaptive memory that learns your business vocabulary across queries.
    </Tip>
  </Step>
  <Step title="Run your first query">
    Open **Chat** and ask something like:

    > How many customers signed up last month and what's the average order value?

    CoreBase generates SQL, the agent executes it against your database, and the model summarizes the rows. Raw values stay on your server — only the redacted answer comes back.
  </Step>
</Steps>
