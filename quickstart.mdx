You need shell access to a server that can reach your database and (optionally) a CoreBase Cloud account if you want the panel, audit log, and Corporate Memory layer.

<Steps>
  <Step title="Install CoreMCP">
    One command — POSIX shell installer detects your OS/arch, verifies SHA256, drops the binary in `PATH`:

    ```bash
    curl -fsSL https://get.corebasehq.com | sh
    ```

    Prefer Docker? `docker pull y11t0/coremcp:latest`. From source? `go build ./cmd/coremcp`. See [Install](/coremcp/install) for all paths.
  </Step>
  <Step title="Configure a source">
    Create `coremcp.yaml` (or override with `--config /path/to/file.yaml`):

    ```yaml
    server:
      transport: stdio

    sources:
      - name: erp_prod
        type: mssql
        dsn: "sqlserver://core_ro:password@10.0.0.5:1433?database=ERP&encrypt=disable"
        readonly: true
    ```

    Use a database user with `SELECT`-only grants. See [Connect a data source](/coremcp/connect) for `mssql`, `rest`, and `graphql` DSN catalogs; full schema in [Configuration reference](/coremcp/configuration).
  </Step>
  <Step title="Wire to an MCP client">
    For Claude Desktop — edit `~/Library/Application Support/Claude/claude_desktop_config.json`:

    ```json
    {
      "mcpServers": {
        "corebase": {
          "command": "/usr/local/bin/coremcp",
          "args": ["serve", "--config", "/etc/coremcp/coremcp.yaml"]
        }
      }
    }
    ```

    Restart Claude. Your tables surface as MCP tools under the hammer icon. Cursor, Continue, Zed: see [MCP clients](/coremcp/clients).
  </Step>
  <Step title="Ask">
    In your editor or Claude Desktop:

    > How many customers signed up last month and what's the average order value?

    The model picks the right MCP tools, CoreMCP runs the SQL against your DB locally, returns rows to the client, the model summarizes. **Raw values stay on your network.**
  </Step>
</Steps>

## Add the cloud layer (optional)

Want a hosted chat UI, RBAC, audit log, Corporate Memory, and the Developer API? Sign up at [corebasehq.com](https://corebasehq.com) — free tier ships with a $1 trial credit.

The cloud panel orchestrates queries through the same CoreMCP agent. Configure your agent's `transport: http` and connect it from **Sources → Add agent**.
