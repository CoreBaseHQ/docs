CoreBase listens to Stripe events to keep your plan and subscription status in sync with what you do in the Stripe Customer Portal. This page is informational — if you're using the managed cloud at `corebasehq.com`, nothing to configure. If you self-host, set the webhook in your own Stripe account.

## Endpoint

```
POST https://api.corebasehq.com/api/webhooks/stripe
```

Self-hosted: replace the domain with yours.

## Signature

Stripe signs every request with the webhook signing secret. Invalid or replayed requests are rejected with `401`. Duplicate deliveries are safe — they're treated as no-ops.

## Subscription events

| Event | Effect |
|---|---|
| `customer.subscription.created` | Activates the chosen plan (Pro / Team) on the organization. |
| `customer.subscription.updated` | Picks up plan changes and status transitions (`trialing`, `past_due`, etc.). |
| `customer.subscription.deleted` | Final cancellation. Organization drops back to the Free plan. |
| `invoice.paid` | Subscription renewal. |

Other events return `200` and are ignored.
